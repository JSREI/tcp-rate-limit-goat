# TCP检测SDK使用示例

本目录包含了TCP检测SDK的各种使用示例，从简单到复杂，展示了SDK的基本功能和高级特性。

## 目录说明

- **simple/** - 基础示例，展示最简单的速率限制检测用法
- **advanced/** - 高级示例，展示动态配置和多检测器组合使用
- **main.go** - 完整示例，展示各种检测器的协同工作方式

## 运行示例

### 基础示例

```bash
cd simple
go run main.go
```

这个示例展示了最基本的速率限制检测功能，包括：
- 使用默认工厂创建检测器
- 将检测器集成到Gin中间件
- 处理超限访问

**控制台输出样例：**
```

启动一个简单的Web服务器，展示速率限制功能
===============================

提示: 快速刷新页面可以触发速率限制
[通过] 允许客户端127.0.0.1:54321访问
[通过] 允许客户端127.0.0.1:54321访问
[拒绝] 客户端127.0.0.1:54321访问频率过高
```

```bash

```

这个示例展示了更高级的功能，包括：

- 多检测器协同工作
- 不同保护模式的切换

**控制台输出样例：**

- 组合使用速率限制和端口递增检测
- 基于不同API路径的保护策略
- 自定义配置选项的使用

## 压力测试

可以使用`ab`工具测试速率限制功能：

```bash
# 发送100个请求，并发10个，测试速率限制效果
ab -n 100 -c 10 http://localhost:8080/rate-test
```
